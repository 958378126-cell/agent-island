# 支持矩阵

| 来源 | 当前状态 | 证据等级 | 对外承诺 |
|---|---|---|---|
| Codex 桌面版 / CLI | 规划中 | 本机只读或手工上报 | 不宣称覆盖桌面版全部实时回合 |
| WorkBuddy | 规划中 | 本地只读候选路径 | 数据库结构随客户端升级可能变化 |
| AutoClaw | 规划中 | 本地会话只读候选路径 | 只有真实生命周期验收后才显示运行任务 |
| 豆包 | 规划中 | 活动推断 | 不称为任务级运行状态或成功结果 |
| 自定义 Agent | 核心契约已定义 | HTTP JSON / JSONL / 命令 JSONL | 接入方必须提供稳定 ID、状态、时间和证据等级 |
| Kimi / 千问 | 规划中 | 官方接口适配器候选 | 托管会话或 Response ID 不等于本机桌面任务总表 |

“规划中”意味着仓库没有足够的真实任务对照证据，不是已接通但暂时隐藏。连接器断开、权限不足、超时或返回未知状态时，统一显示来源健康问题和 `unknown`，不会伪装成空闲或完成。
