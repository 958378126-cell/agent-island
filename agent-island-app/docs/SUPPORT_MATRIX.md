# 支持矩阵

| 来源 | 当前状态 | 证据等级 | 对外承诺 |
|---|---|---|---|
| Codex 桌面版 / CLI | 已实现，尽力支持 | 本地 rollout JSONL；`app-server` 进程回退 | 不承诺覆盖所有版本或所有暂停状态 |
| WorkBuddy | 已实现，尽力支持 | 本地数据库 / JSONL 回退 | 数据库结构随客户端升级可能变化 |
| AutoClaw | 已实现，尽力支持 | 本地会话、锁和日志只读候选路径 | 只有可观察到活动证据才显示运行任务 |
| 豆包 | 已实现，活动推断 | 聊天 IndexedDB 文件活动 | 不称为任务级运行状态或成功结果 |
| 自定义 Agent | 核心契约已定义 | HTTP JSON / JSONL / 命令 JSONL | 接入方必须提供稳定 ID、状态、时间和证据等级 |
| Kimi / 千问 | 提供示例适配器 | 官方接口命令 JSONL 适配器 | 托管会话或 Response ID 不等于本机桌面任务总表 |

“规划中”意味着仓库没有足够的真实任务对照证据，不是已接通但暂时隐藏。连接器断开、权限不足、超时或返回未知状态时，统一显示来源健康问题和 `unknown`，不会伪装成空闲或完成。
